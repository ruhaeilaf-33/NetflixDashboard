# 🎬 Netflix Movies & TV Shows — Tableau Dashboard

An interactive **Tableau dashboard** designed to explore and visualize Netflix's
Movies and TV Shows catalogue. The dashboard provides insights into content
distribution across countries, genres, ratings, release years, and content type.

## 🔎 Project Overview

Netflix has a large and diverse content library spanning multiple countries,
genres, ratings, and release periods.

This project uses **data visualization and interactive dashboarding** to
analyze the Netflix catalogue and make key patterns easier to understand.

The dashboard allows users to explore the data through interactive filters
and multiple visualization techniques.

---

## 🎯 Objectives

- Analyze the distribution of **Movies vs TV Shows**
- Explore Netflix content across different **countries**
- Identify the **most common genres**
- Understand the distribution of **content ratings**
- Analyze how Netflix content has changed across **release years**
- Compare content trends using multiple visualization techniques
- Build an interactive and visually engaging dashboard using Tableau

---

## 📈 Dashboard Features

### 🌍 Content Distribution by Country
A geographical visualization showing the number of Movies and TV Shows
available across different countries.

### ⭐ Ratings Analysis
Visualizes the distribution of Netflix titles across different ratings such
as TV-MA, TV-14, R, PG-13, and others.

### 🎭 Top 10 Genres
Highlights the most frequently occurring genres in the dataset.

### 🎬 Movies vs TV Shows
A visual comparison of the proportion of Movies and TV Shows available on
Netflix.

### 📅 Content by Release Year
Shows how the number of Netflix titles varies across different release years.

### 🌳 Genre Treemap
Provides a compact visual representation of genre distribution.

### 🫧 Bubble Chart
Uses a bubble-based visualization to explore relationships between release
years and content ratings.

### 📊 Gantt Chart
Provides a country-wise view of content distribution across release years.

### 🔥 Highlight Table
Uses color intensity to make patterns across content categories easier to
identify.
